theSVG 4.0: UI icons are here. The major version marks the release that adds a second section of 129 UI icons (outline, glass, duotone, offset, fill, pixel and depth), published as the new `@thesvg/ui`, `@thesvg/ui-react`, `@thesvg/ui-vue`, `@thesvg/ui-svelte` and `@thesvg/ui-react-native` packages. There are no API changes in this package: existing brand imports, names and files are unchanged.
