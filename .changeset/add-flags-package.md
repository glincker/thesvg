Add the Flags category: every ISO 3166-1 country plus England, Scotland, Wales, Catalonia, the Basque Country, Galicia, the EU and the UN, each in 4x3, square and circle. New package `@thesvg/flags` with per-flag React components, plain SVG exports, search metadata and `getFlagForLocale`. The MCP search lists exact code, number and emoji matches first.
