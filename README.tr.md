## Neden theSVG

Marka logoları basın kitlerine, Figma dosyalarına ve rastgele GitHub repolarına dağılmış durumda. **theSVG** SVG ikonları için tek kaynaktır: marka logoları, bulut mimari diyagramları ve bize ait bir arayüz ikon seti. Aranabilir, sürümlü; npm paketi, CDN, CLI, API ve MCP sunucusu olarak kullanılabilir.

Her geliştirici bir şirket logosu aramıştır: üç tık derine gömülmüş bir basın kiti, retina ekranda bulanıklaşan bir PNG, aslında dört renkli olan sözde "mono" bir dosya, geçen ay değişmiş bir logo. Çoğu ikon seti arayüz glifleri sunar. Marka logolarını gerçek, sürümlü ve güvenilir veri olarak ele alan olmadı.

theSVG alıyor. Her logonun **resmi, temiz, eksiksiz ve güncel** olduğu tek bir açık katalog ve projenizin ihtiyaç duyduğu her biçimde sunuluyor.

### Neden yaptık

theSVG bir pull request ile başladı. Kendi ürünümüz [AskVerdict](https://www.askverdict.ai) logosunu mevcut bir açık kaynak logo kütüphanesine eklemeye çalıştık ve proje kapsamı dışında kaldığı gerekçesiyle reddedildi; küratörlü bir set için makul bir karar. Bu, büyük küçük her gerçek markanın basit bir incelemeyle eklenebildiği bir katalog istememize yol açtı. theSVG bugün 7,900'den fazla ikon barındırıyor; hepsi resmi marka varlıklarından alınıyor ve birleştirilmeden önce kontrol ediliyor.

### theSVG standardı

Katalogdaki her ikonun uyması gereken ölçüt ve bir marka SVG'sinin her yerde ne anlama gelmesini istediğimiz:

| İlke | Pratikte ne anlama gelir |
| --- | --- |
| **Resmi, değiştirilmemiş** | Markanın kendi kitinden veya sitesinden alınır; her kayıtta lisans ve yönergeler bağlantısı bulunur. Yeniden çizim yok. |
| **Eksiksiz varyantlar** | Öngörülebilir tek bir adlandırma düzeni altında `default`, `mono`, `light`, `dark` ve `wordmark`; böylece `{slug}/{variant}.svg` her zaman çalışır. |
| **Gerçekten temiz** | CI'da değişen her dosyada bir doğrulayıcı çalışır: betik yok, gömülü raster yok, `null` veya `NaN` değeri yok, mono dosyalar gerçekten tek renk, `viewBox` her zaman mevcut. |
| **Yeniden markalaşmada geçmiş korunur** | Bir marka logosunu değiştirdiğinde yeni işaret güncel olur, eskisi `-legacy` kaydı olarak saklanır ve iki yönlü bağlanır. Hiçbir şey sessizce kaybolmaz. |
| **Makine tarafından okunabilir** | Statik bir manifest, `llms.txt`, bir MCP sunucusu ve kararlı CDN URL'leri; böylece araçlar ve yapay zeka asistanları logoları insanlar kadar güvenilir biçimde kullanabilir. |
| **Herkese açık** | MIT lisanslı kod, hesap yok, API anahtarı yok, kapı bekçiliği yok. Bir marka gerçekse, buraya aittir. |

Aradığınız logo kütüphanesi buysa, yapabileceğiniz en faydalı şey **[repoya yıldız vermek](https://github.com/glincker/thesvg)**. Diğer geliştiriciler onu böyle buluyor.

### UI ikonları

**theSVG 4.0 ile yeni.** Marka kataloğunun yanında theSVG, [thesvg.org/ui](https://thesvg.org/ui) adresinde **kendi çizdiğimiz arayüz ikonlarından** oluşan bir set de sunuyor. Bugün 129 ikon var; her biri yedi görünümde (outline, glass, duotone, offset, fill, glass outline ve depth), hepsi `currentColor` kullanıyor ve küçük paketler halinde yenileri geliyor. Ayrı bir bölüm olarak kendi verisi, paketleri ve testleri var; iki ikon türü veri veya kod bakımından asla karışmıyor. Aşağıdaki [UI ikonları](#ui-ikonları-1) bölümüne bakın.

### Bayraklar

[thesvg.org/collection/flags](https://thesvg.org/collection/flags) adresinden göz atın. Her ISO 3166-1 ülkesi; ayrıca İngiltere, İskoçya, Galler, Katalonya, Bask Bölgesi, Galiçya, Valensiya Topluluğu, Balear Adaları, Kanarya Adaları, Korsika, Oksitanya, AB ve BM, üç biçimde. Slug'lar `flag-<code>` şeklindedir (`flag-us`, `flag-gb-eng`); varyantlar `default` (4x3), `square` ve `circle`.

```bash
npm i @thesvg/flags
```

```tsx
import { FlagUs } from "@thesvg/flags/react/us";
import { getFlagForLocale } from "@thesvg/flags/locale";

<FlagUs variant="circle" size={32} />
```

Düz görsel için kurulum gerekmez: `https://cdn.jsdelivr.net/npm/@thesvg/flags/dist/svg/4x3/us.svg` (diğer biçimler için `1x1` veya `circle` kullanın).

Sitede her bayrağın kendi sayfası (`/icon/flag-us`) vardır: renk paleti, kopyalama ve indirme düğmeleri, nasıl kullanılır kartı (npm, CLI ve CDN) ve taranabilir bilgiler. Koleksiyon sayfası bölgeye, renge veya yerele göre filtrelenir; üst bardaki arama bayrakları ayrı bir bölümde listeler, böylece marka ikonları önde kalır.

Bayrak bir ülkedir, dil değil: yanında ana dilin adını gösterin. Rehber: [docs/flags.md](./docs/flags.md).

## Hızlı başlangıç

```bash
# Add a single icon to your project
npx @thesvg/cli add github

# Or install the package and import only what you use
npm install thesvg
```

```ts
import github from "thesvg/github";

github.svg;      // raw SVG string
github.title;    // "GitHub"
github.hex;      // "181717"
```

```html
<!-- Or use the CDN, no install -->
<img src="https://thesvg.org/icons/github/default.svg" width="32" height="32" alt="GitHub" />
```

## Varyantlar

İkonlar, her tasarım bağlamına uymak için en fazla 7 varyantı destekler:

| Varyant | Anahtar | Açıklama |
|---------|-----|-------------|
| Default | `default` | Birincil marka rengi |
| Mono | `mono` | Metin rengini devralır |
| Light | `light` | Açık arka planlar için koyu dolgu |
| Dark | `dark` | Koyu arka planlar için açık dolgu |
| Wordmark | `wordmark` | Tam yazı logosu |
| Wordmark Light | `wordmarkLight` | Beyaz yazı logosu |
| Wordmark Dark | `wordmarkDark` | Koyu yazı logosu |

Her ikonda tüm varyantlar bulunmaz. `default` her zaman vardır.

## UI ikonları

Kendi çizdiğimiz, yedi görünümlü arayüz ikonları. [thesvg.org/ui](https://thesvg.org/ui) adresinden göz atın.

```bash
npm install @thesvg/ui-react
```

```tsx
import { BellIcon, BellGlassIcon } from "@thesvg/ui-react";

// Outline is the plain name, every other look adds its name.
<BellIcon size={24} aria-label="Notifications" />
<BellGlassIcon size={32} />
```

Görünüm başına bir export, içe aktarmadığınız görünümün paketinize asla girmemesi demektir. Vue, Svelte ve React Native paketleri aynı adlandırmayı izler (`@thesvg/ui-vue`, `@thesvg/ui-svelte`, `@thesvg/ui-react-native`).

| Ne | Nerede |
|------|-------|
| Tek ikon dosyası | `https://thesvg.org/ui/{slug}/{look}.svg` |
| Tek görünümdeki tüm ikonlar | `https://cdn.jsdelivr.net/gh/glincker/thesvg@main/src/data/ui/looks/{look}.json` |
| Manifest (slug'lar, etiketler, kategoriler, kalite) | `https://cdn.jsdelivr.net/gh/glincker/thesvg@main/src/data/ui-icons.json` |
| CLI | `npx @thesvg/cli add ui:bell --look glass` |

Görünümler: `outline`, `glass`, `duotone`, `offset`, `fill`, `glass-outline`, `depth`. UI ikonları, kodun geri kalanı gibi [MIT lisansı](./LICENSE) altında yayımlanan özgün çizimlerdir. İkon eklemek veya değiştirmek için [UI ikonlarına katkı](./CONTRIBUTING.md#ui-icons) bölümüne bakın.

## API

<details>
<summary>Statik manifest, aynalar ve örnekler</summary>

thesvg tamamen statik bir site olarak çalışır ve bir CDN'den sunulur. Dinamik API yoktur; bunun yerine önceden oluşturulmuş iki JSON manifest tüm kullanım senaryolarını karşılar. Arama, filtreleme ve sayfalama istemci tarafında yapılır.

Temel URL: `https://thesvg.org`

| Uç nokta | Açıklama |
|----------|-------------|
| `GET /api/registry.json` | Tam ikon manifesti (slug, başlık, takma adlar, kategoriler, hex, url, varyant anahtarları) |
| `GET /api/categories.json` | Sayılarla birlikte kategori listesi |
| `GET /icons/{slug}/{variant}.svg` | Ham SVG dosyası (örn. `/icons/openai/default.svg`) |

```bash
# Fetch the manifest once, filter client-side
curl "https://thesvg.org/api/registry.json" | jq '.icons[] | select(.slug | contains("openai"))'

# Then pull the SVG you want
curl "https://thesvg.org/icons/openai/default.svg"
```

### Aynalar

Yoğun trafikli uygulamalar için doğrudan `thesvg.org`'a gitmek yerine jsDelivr kullanın (ücretsiz, GitHub destekli):

```
https://cdn.jsdelivr.net/gh/glincker/thesvg@main/src/data/icons.json
https://cdn.jsdelivr.net/gh/glincker/thesvg@main/public/icons/{slug}/{variant}.svg
```

`src/data/icons.json` ana kaynak manifesttir (`/api/registry.json` dosyasını oluşturan aynı veri; ikon başına `license` ve `dateAdded` dahil tüm alanlarla).

Repoyu klonlayıp (~30 MB) kendi sunucunuzda da barındırabilirsiniz. Kod tabanı MIT lisanslıdır; tek tek marka ikonları ilgili sahiplerinin ticari markası olmaya devam eder ([LEGAL.md](./LEGAL.md) dosyasına bakın).

> `api.thesvg.org` adresinde, gelişmiş özellikler (arama alaka düzeyi, kullanım analitiği, webhook'lar) için kimlik doğrulamalı, token tabanlı bir API yol haritasında. O zamana kadar desteklenen entegrasyon yolu yukarıdaki statik manifesttir.

</details>

## Yerelde çalıştırın

[Node.js](https://nodejs.org) 20 veya üstü ile [pnpm](https://pnpm.io) gerekir.

```bash
git clone https://github.com/glincker/thesvg.git
cd thesvg
pnpm install
pnpm dev          # http://localhost:3333
```

| Komut | Ne yapar |
| --- | --- |
| `pnpm dev` | Siteyi 3333 portunda hot reload ile başlatır |
| `pnpm build` | API'yi, `llms.txt`'i, feed'i ve ikon tonlarını yeniden üretir, ardından statik siteyi derler |
| `pnpm lint` | ESLint çalıştırır |
| `pnpm test` | Vitest paketini ve CLI ile ikon paketi testlerini çalıştırır |
| `npx tsx scripts/validate-icons.ts` | Her SVG'yi betik, hatalı değer, mono olmayan mono dosya ve eksik `viewBox` açısından denetler |

**İkon ekleyin:** dosyaları `public/icons/{slug}/` altına koyun (`default.svg`, ayrıca geçerli olanlara göre `mono`, `light`, `dark` veya `wordmark`), slug'ı `src/data/icons.json` içine kaydedin, doğrulayıcıyı çalıştırın, ardından pull request açın. Tüm kurallar [CONTRIBUTING.md](./CONTRIBUTING.md) içinde.
