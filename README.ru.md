## Почему theSVG

Логотипы брендов разбросаны по пресс-китам, файлам Figma и случайным репозиториям GitHub. **theSVG** это единый источник SVG-иконок: логотипы брендов, схемы облачной архитектуры и набор наших собственных интерфейсных иконок. Есть поиск и версионирование, а получить их можно как npm-пакеты, через CDN, CLI, API и MCP-сервер.

Каждый разработчик искал логотип компании: пресс-кит спрятан за тремя кликами, PNG расплывается на retina-экране, "монохромный" файл на самом деле в четыре цвета, а сам логотип сменили в прошлом месяце. Большинство наборов иконок покрывают только интерфейсные глифы. Логотипы брендов никто не считал настоящими, версионируемыми и надёжными данными.

theSVG относится к ним именно так. Это единый открытый каталог, где каждый логотип **официальный, чистый, полный и актуальный**, и он доставляется в том виде, который нужен вашему проекту.

### Зачем мы это сделали

theSVG начался с pull request. Мы попытались добавить логотип нашего собственного продукта, [AskVerdict](https://www.askverdict.ai), в существующую open source библиотеку логотипов, и его отклонили как выходящий за рамки проекта. Для отобранной коллекции это справедливое решение. Так появилось желание создать каталог, куда можно добавить любой настоящий бренд, большой или малый, после простого ревью. Сегодня в theSVG более 7 900 иконок из официальных материалов брендов, и каждая проверяется перед слиянием.

**ДОМ ДЛЯ КАЖДОГО БРЕНДА.**

### Стандарт theSVG

Требования, которым соответствует каждая иконка в каталоге, и то, что, по нашему мнению, должен означать SVG бренда везде:

| Принцип | Что это значит на практике |
| --- | --- |
| **Официальные, без правок** | Берутся из собственного кита или сайта бренда, у каждой записи есть лицензия и ссылка на руководство по использованию. Никаких перерисовок. |
| **Полный набор вариантов** | `default`, `mono`, `light`, `dark` и `wordmark` с единой предсказуемой схемой имён, поэтому `{slug}/{variant}.svg` всегда работает. |
| **Действительно чистые** | Валидатор в CI проверяет каждый изменённый файл: никаких скриптов, встроенных растров, значений `null` или `NaN`, mono-файлы реально одноцветные, `viewBox` есть всегда. |
| **История ребрендингов сохраняется** | Когда бренд меняет логотип, новый знак становится текущим, а старый остаётся записью `-legacy` с перекрёстными ссылками. Ничто не исчезает молча. |
| **Машиночитаемость** | Статический манифест, `llms.txt`, MCP-сервер и стабильные CDN-ссылки, чтобы инструменты и AI-ассистенты работали с логотипами так же надёжно, как люди. |
| **Открыто для всех** | Код под MIT, без аккаунтов и API-ключей, без ограничений на вход. Если бренд настоящий, ему здесь место. |

Если это та библиотека логотипов, о которой вы мечтали, самое полезное, что вы можете сделать, это **[поставить звезду репозиторию](https://github.com/glincker/thesvg)**. Так о нём узнают другие разработчики.

### UI-иконки

**Новое в theSVG 4.0.** Помимо каталога брендов, theSVG включает набор **интерфейсных иконок, которые мы рисуем сами**, на [thesvg.org/ui](https://thesvg.org/ui). Сейчас их 129, каждая в семи стилях (контур, стекло, двухтоновый, со смещением, заливка, стеклянный контур и глубина), все используют `currentColor`, новые появляются небольшими порциями. Это отдельный раздел со своими данными, пакетами и тестами, и данные и код двух видов иконок никогда не смешиваются. См. [UI-иконки](#ui-иконки-1) ниже.

### Флаги

Смотрите на [thesvg.org/collection/flags](https://thesvg.org/collection/flags). Все страны ISO 3166-1 плюс Англия, Шотландия, Уэльс, Каталония, Страна Басков, Галисия, Валенсийское сообщество, Балеарские острова, Канарские острова, Корсика, Окситания, ЕС и ООН, в трёх формах. Slug имеет вид `flag-<code>` (`flag-us`, `flag-gb-eng`); варианты: `default` (4x3), `square` и `circle`.

```bash
npm i @thesvg/flags
```

```tsx
import { FlagUs } from "@thesvg/flags/react/us";
import { getFlagForLocale } from "@thesvg/flags/locale";

<FlagUs variant="circle" size={32} />
```

Для обычной картинки установка не нужна: `https://cdn.jsdelivr.net/npm/@thesvg/flags/dist/svg/4x3/us.svg` (для других форм используйте `1x1` или `circle`).

На сайте у каждого флага есть своя страница (`/icon/flag-us`) с цветовой палитрой, кнопками копирования и скачивания, карточкой "как использовать" (npm, CLI и CDN) и фактами, доступными для индексации. Страница коллекции фильтрует по региону, цвету или локали, а поиск в шапке выводит флаги в отдельном разделе, чтобы иконки брендов оставались первыми.

Флаг обозначает страну, а не язык: рядом с ним лучше показывать название языка на нём самом. Руководство: [docs/flags.md](./docs/flags.md).

## Варианты

Иконки поддерживают до 7 вариантов под любой дизайнерский контекст:

| Вариант | Ключ | Описание |
|---------|-----|-------------|
| По умолчанию | `default` | Основной цвет бренда |
| Моно | `mono` | Наследует цвет текста |
| Светлый | `light` | Тёмная заливка, для светлых фонов |
| Тёмный | `dark` | Светлая заливка, для тёмных фонов |
| Вордмарк | `wordmark` | Полный текстовый логотип |
| Вордмарк светлый | `wordmarkLight` | Белый текстовый логотип |
| Вордмарк тёмный | `wordmarkDark` | Тёмный текстовый логотип |

Не у каждой иконки есть все варианты. `default` есть всегда.

## UI-иконки

Интерфейсные иконки, которые мы рисуем сами, в семи стилях. Смотрите на [thesvg.org/ui](https://thesvg.org/ui).

```bash
npm install @thesvg/ui-react
```

```tsx
import { BellIcon, BellGlassIcon } from "@thesvg/ui-react";

// Outline is the plain name, every other look adds its name.
<BellIcon size={24} aria-label="Notifications" />
<BellGlassIcon size={32} />
```

Один экспорт на стиль, поэтому стиль, который вы не импортируете, не попадает в сборку. Пакеты для Vue, Svelte и React Native используют те же имена (`@thesvg/ui-vue`, `@thesvg/ui-svelte`, `@thesvg/ui-react-native`).

| Что | Где |
|------|-------|
| Один файл иконки | `https://thesvg.org/ui/{slug}/{look}.svg` |
| Все иконки одного стиля | `https://cdn.jsdelivr.net/gh/glincker/thesvg@main/src/data/ui/looks/{look}.json` |
| Манифест (slug, теги, категории, качество) | `https://cdn.jsdelivr.net/gh/glincker/thesvg@main/src/data/ui-icons.json` |
| CLI | `npx @thesvg/cli add ui:bell --look glass` |

Стили: `outline`, `glass`, `duotone`, `offset`, `fill`, `glass-outline`, `depth`. UI-иконки нарисованы нами с нуля и выпускаются под [лицензией MIT](./LICENSE), как и остальной код. Чтобы добавить или изменить иконки, см. [Вклад в UI-иконки](./CONTRIBUTING.md#ui-icons).

## API

<details>
<summary>Статический манифест, зеркала и примеры</summary>

thesvg это полностью статический сайт, который раздаётся с CDN. Динамического API нет: все сценарии покрывают два заранее собранных JSON-манифеста. Поиск, фильтрация и пагинация выполняются на клиенте.

Базовый URL: `https://thesvg.org`

| Эндпоинт | Описание |
|----------|-------------|
| `GET /api/registry.json` | Полный манифест иконок (slug, название, алиасы, категории, hex, url, ключи вариантов) |
| `GET /api/categories.json` | Список категорий с количеством |
| `GET /icons/{slug}/{variant}.svg` | Исходный SVG-файл (например, `/icons/openai/default.svg`) |

```bash
# Fetch the manifest once, filter client-side
curl "https://thesvg.org/api/registry.json" | jq '.icons[] | select(.slug | contains("openai"))'

# Then pull the SVG you want
curl "https://thesvg.org/icons/openai/default.svg"
```

### Зеркала

Для приложений с высокой нагрузкой используйте jsDelivr (бесплатно, на базе GitHub) вместо прямых обращений к `thesvg.org`:

```
https://cdn.jsdelivr.net/gh/glincker/thesvg@main/src/data/icons.json
https://cdn.jsdelivr.net/gh/glincker/thesvg@main/public/icons/{slug}/{variant}.svg
```

`src/data/icons.json` это эталонный манифест (те же данные, из которых собирается `/api/registry.json`, с полными полями каждой иконки, включая `license` и `dateAdded`).

Вы также можете клонировать репозиторий (около 30 МБ) и разместить у себя. Кодовая база под лицензией MIT; отдельные иконки брендов остаются товарными знаками их владельцев (см. [LEGAL.md](./LEGAL.md)).

> В планах закрытый API с токенами на `api.thesvg.org` для расширенных возможностей (релевантность поиска, аналитика использования, вебхуки). До тех пор статический манифест выше остаётся поддерживаемым способом интеграции.

</details>

## Запуск локально

Вам понадобятся [Node.js](https://nodejs.org) 20 или новее и [pnpm](https://pnpm.io).

```bash
git clone https://github.com/glincker/thesvg.git
cd thesvg
pnpm install
pnpm dev          # http://localhost:3333
```

| Команда | Что делает |
| --- | --- |
| `pnpm dev` | Запускает сайт с горячей перезагрузкой на порту 3333 |
| `pnpm build` | Пересобирает API, `llms.txt`, ленту и тона иконок, затем собирает статический сайт |
| `pnpm lint` | Запускает ESLint |
| `pnpm test` | Запускает набор Vitest, а также тесты CLI и пакета иконок |
| `npx tsx scripts/validate-icons.ts` | Проверяет каждый SVG на скрипты, некорректные значения, не одноцветные mono-файлы и отсутствие `viewBox` |

**Добавить иконку:** положите файлы в `public/icons/{slug}/` (`default.svg`, а также `mono`, `light`, `dark` или `wordmark`, если они применимы), зарегистрируйте slug в `src/data/icons.json`, запустите валидатор и откройте pull request. Полные правила в [CONTRIBUTING.md](./CONTRIBUTING.md).
