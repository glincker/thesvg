## なぜ theSVG か

ブランドロゴは、プレスキット、Figma ファイル、出所の分からない GitHub リポジトリに散らばっています。**theSVG** は SVG アイコンの唯一の情報源です。ブランドロゴ、クラウドアーキテクチャ図、そして私たちが描いた UI アイコンを揃えています。検索でき、バージョン管理され、npm パッケージ、CDN、CLI、API、MCP サーバーとして使えます。

会社のロゴを探し回った経験は、開発者なら誰にでもあるでしょう。3クリック奥に埋もれたプレスキット、Retina で滲む PNG、実は4色使われている「モノクロ」ファイル、先月変わってしまったロゴ。ほとんどのアイコンセットは UI のグリフが中心で、ブランドロゴを、バージョン管理された信頼できるデータとして扱うものはありませんでした。

theSVG はそれを実現します。すべてのロゴが**公式で、クリーンで、網羅的で、最新**であるひとつのオープンなカタログで、プロジェクトに必要な形でそのまま届けます。

### 作った理由

theSVG は1つのプルリクエストから始まりました。自社プロダクトである [AskVerdict](https://www.askverdict.ai) のロゴを既存のオープンソースのロゴライブラリに追加しようとしたところ、そのプロジェクトの対象外として断られました。厳選されたセットとしては妥当な判断です。そこで、大手でも小さなブランドでも、実在するブランドなら簡単なレビューで追加できるカタログがほしいと考えるようになりました。現在 theSVG には7,900以上のアイコンがあり、すべて公式のブランド素材から取得し、マージ前に検証しています。

**すべてのブランドに居場所を。**

### theSVG の基準

カタログのすべてのアイコンが満たす基準であり、ブランド SVG がどこでもそうあってほしいと私たちが考える姿です。

| 原則 | 実際の意味 |
| --- | --- |
| **公式、無加工** | ブランド自身のキットやサイトから取得し、すべての項目にライセンスとガイドラインへのリンクを付けています。再描画はしません。 |
| **バリアントが揃っている** | `default`、`mono`、`light`、`dark`、`wordmark` を一貫した命名規則で提供するので、`{slug}/{variant}.svg` が常に使えます。 |
| **本当にクリーン** | 変更されたすべてのファイルに対して CI でバリデーターが動きます。スクリプト、埋め込みラスター画像、`null` や `NaN` の値は不可。モノクロファイルは本当に単色で、`viewBox` は必ず存在します。 |
| **リブランドしても履歴を残す** | ブランドがロゴを変更したら、新しいマークが現行となり、旧版は `-legacy` エントリとして双方向にリンクして残します。何も黙って消えることはありません。 |
| **機械可読** | 静的マニフェスト、`llms.txt`、MCP サーバー、安定した CDN URL により、ツールや AI アシスタントも人間と同じように確実にロゴを使えます。 |
| **誰にでも開かれている** | MIT ライセンスのコード、アカウント不要、API キー不要、門前払いなし。実在するブランドなら、ここに居場所があります。 |

探していたのがこんなロゴライブラリなら、いちばん助かるのは **[リポジトリに Star を付けること](https://github.com/glincker/thesvg)** です。ほかの開発者が見つけるきっかけになります。

### UI アイコン

**theSVG 4.0 の新機能。** ブランドカタログに加えて、theSVG は**私たち自身が描いたインターフェースアイコン**を [thesvg.org/ui](https://thesvg.org/ui) で提供しています。現在129個。それぞれ7種類のスタイル (アウトライン、グラス、デュオトーン、オフセット、フィル、グラスアウトライン、デプス) があり、すべて `currentColor` を使います。今後も少しずつ追加していきます。独立したセクションとして専用のデータ、パッケージ、テストを持ち、2種類のアイコンのデータとコードが混ざることはありません。詳しくは下の [UI アイコン](#ui-アイコン-1) を参照してください。

### 主な特長

- **<!-- flags:total-icons -->7,900+<!-- /flags:total-icons --> 個のアイコン**、複数のコレクションを収録
- **4,800以上のブランドアイコン**、150以上のカテゴリ
- **21のブランドファミリー**: Amazon、Google、Microsoft などのすべての製品を、所有者ごとにグループ化
- **858個の認証バッジアイコン**: 2FA/認証アプリ向けの円形アイコンバッジ
- **739個の AWS アーキテクチャアイコン** (2026-Q1)
- **626個の Azure サービスアイコン** (2026-Q1)
- **256個のコミュニティ厳選アイコン**: 開発ツール、データベース、フレームワーク
- **214個の Google Cloud アイコン** (2026-Q1)
- **<!-- flags:count -->263<!-- /flags:count --> 個の国・地域の旗**: ISO 3166-1 に加え、イングランド、スコットランド、ウェールズ、カタルーニャなど。4x3、正方形、円形
- **<!-- flags:total-variants -->14,700+<!-- /flags:total-variants --> 個の SVG バリアント**: カラー、モノ、ライト、ダーク、ワードマーク、国旗の形状
- **ツリーシェイク対応**: 1つのアイコンだけ import すれば、そのアイコンだけが出荷されます
- **TypeScript ファースト**: 完全な型付け、ESM/CJS の両対応
- **フレームワーク非依存**: React、Vue、Svelte、素の HTML、CDN のどれでも
- **AI 対応**: Claude、Cursor、Windsurf 向けの MCP サーバー

### 国旗

[thesvg.org/collection/flags](https://thesvg.org/collection/flags) で閲覧できます。ISO 3166-1 のすべての国に加え、イングランド、スコットランド、ウェールズ、カタルーニャ、バスク、ガリシア、バレンシア州、バレアレス諸島、カナリア諸島、コルシカ、オクシタニア、EU、国連を、3つの形状で収録しています。スラッグは `flag-<code>` (`flag-us`、`flag-gb-eng`)、バリアントは `default` (4x3)、`square`、`circle` です。

```bash
npm i @thesvg/flags
```

```tsx
import { FlagUs } from "@thesvg/flags/react/us";
import { getFlagForLocale } from "@thesvg/flags/locale";

<FlagUs variant="circle" size={32} />
```

画像として使うだけならインストールは不要です: `https://cdn.jsdelivr.net/npm/@thesvg/flags/dist/svg/4x3/us.svg` (ほかの形状は `1x1` または `circle` を使います)。

サイトでは、すべての国旗に専用ページ (`/icon/flag-us`) があり、カラーパレット、コピーとダウンロードのボタン、使い方カード (npm、CLI、CDN)、クロール可能な情報が載っています。コレクションページでは地域、色、ロケールで絞り込めます。ヘッダーの検索では国旗が別セクションに表示されるので、ブランドアイコンが先頭に来ます。

国旗は国を表すもので、言語を表すものではありません。横に、その言語での名称を併記してください。ガイド: [docs/flags.md](./docs/flags.md)。

## バリアント

アイコンは、あらゆるデザインの場面に合わせて最大7種類のバリアントに対応しています。

| バリアント | キー | 説明 |
|---------|-----|-------------|
| デフォルト | `default` | メインのブランドカラー |
| モノ | `mono` | テキストの色を継承 |
| ライト | `light` | 明るい背景向けの濃い塗り |
| ダーク | `dark` | 暗い背景向けの明るい塗り |
| ワードマーク | `wordmark` | 文字のロゴ全体 |
| ワードマーク (ライト) | `wordmarkLight` | 白い文字のロゴ |
| ワードマーク (ダーク) | `wordmarkDark` | 濃い文字のロゴ |

すべてのアイコンに全バリアントがあるわけではありません。`default` は必ずあります。

## UI アイコン

私たち自身が描いたインターフェースアイコンを、7種類のスタイルで。[thesvg.org/ui](https://thesvg.org/ui) で閲覧できます。

```bash
npm install @thesvg/ui-react
```

```tsx
import { BellIcon, BellGlassIcon } from "@thesvg/ui-react";

// Outline is the plain name, every other look adds its name.
<BellIcon size={24} aria-label="Notifications" />
<BellGlassIcon size={32} />
```

スタイルごとに1つのエクスポートなので、import しないスタイルがバンドルに入ることはありません。Vue、Svelte、React Native のパッケージも同じ命名規則に従います (`@thesvg/ui-vue`、`@thesvg/ui-svelte`、`@thesvg/ui-react-native`)。

| 内容 | 場所 |
|------|-------|
| アイコン1つのファイル | `https://thesvg.org/ui/{slug}/{look}.svg` |
| 1つのスタイルの全アイコン | `https://cdn.jsdelivr.net/gh/glincker/thesvg@main/src/data/ui/looks/{look}.json` |
| マニフェスト (スラッグ、タグ、カテゴリ、品質) | `https://cdn.jsdelivr.net/gh/glincker/thesvg@main/src/data/ui-icons.json` |
| CLI | `npx @thesvg/cli add ui:bell --look glass` |

スタイル: `outline`、`glass`、`duotone`、`offset`、`fill`、`glass-outline`、`depth`。UI アイコンはすべて私たちのオリジナルで、コードの他の部分と同じく [MIT ライセンス](./LICENSE) で公開しています。アイコンを追加、変更するには [UI アイコンへの貢献](./CONTRIBUTING.md#ui-icons) を参照してください。

## API

<details>
<summary>静的マニフェスト、ミラー、使用例</summary>

thesvg は完全な静的サイトとして CDN から配信されます。動的な API はなく、代わりに事前生成した JSON マニフェストであらゆる用途をカバーします。検索、絞り込み、ページネーションはクライアント側で行います。

ベース URL: `https://thesvg.org`

| エンドポイント | 説明 |
|----------|-------------|
| `GET /api/registry.json` | アイコン全体のマニフェスト (スラッグ、タイトル、エイリアス、カテゴリ、hex、url、バリアントのキー) |
| `GET /api/categories.json` | 件数付きのカテゴリ一覧 |
| `GET /icons/{slug}/{variant}.svg` | 生の SVG ファイル (例: `/icons/openai/default.svg`) |

```bash
# Fetch the manifest once, filter client-side
curl "https://thesvg.org/api/registry.json" | jq '.icons[] | select(.slug | contains("openai"))'

# Then pull the SVG you want
curl "https://thesvg.org/icons/openai/default.svg"
```

### ミラー

トラフィックの多いアプリでは、`thesvg.org` に直接アクセスする代わりに jsDelivr (無料、GitHub ベース) を使ってください。

```
https://cdn.jsdelivr.net/gh/glincker/thesvg@main/src/data/icons.json
https://cdn.jsdelivr.net/gh/glincker/thesvg@main/public/icons/{slug}/{variant}.svg
```

`src/data/icons.json` は信頼できる唯一のマニフェストです (`/api/registry.json` を生成するのと同じデータで、`license` や `dateAdded` を含むアイコンごとの全フィールドを持ちます)。

リポジトリ (約30 MB) をクローンしてセルフホストすることもできます。コードベースは MIT ライセンスですが、個々のブランドアイコンはそれぞれの所有者の商標のままです ([LEGAL.md](./LEGAL.md) を参照)。

> 高度な機能 (検索の関連度、利用状況の分析、Webhook) 向けに、トークン認証の API を `api.thesvg.org` で提供する予定です。それまでは、上記の静的マニフェストが公式にサポートする連携方法です。

</details>

## ローカルで動かす

[Node.js](https://nodejs.org) 20 以降と [pnpm](https://pnpm.io) が必要です。

```bash
git clone https://github.com/glincker/thesvg.git
cd thesvg
pnpm install
pnpm dev          # http://localhost:3333
```

| コマンド | 内容 |
| --- | --- |
| `pnpm dev` | ポート 3333 でホットリロード付きのサイトを起動します |
| `pnpm build` | API、`llms.txt`、フィード、アイコンのトーンを再生成してから、静的サイトをビルドします |
| `pnpm lint` | ESLint を実行します |
| `pnpm test` | Vitest のスイートに加え、CLI と icons パッケージのテストを実行します |
| `npx tsx scripts/validate-icons.ts` | すべての SVG について、スクリプト、不正な値、単色でないモノファイル、`viewBox` の欠落を検査します |

**アイコンを追加する:** `public/icons/{slug}/` にファイルを置き (`default.svg` に加え、必要に応じて `mono`、`light`、`dark`、`wordmark`)、`src/data/icons.json` にスラッグを登録し、バリデーターを実行して、プルリクエストを送ってください。詳しいルールは [CONTRIBUTING.md](./CONTRIBUTING.md) にあります。
