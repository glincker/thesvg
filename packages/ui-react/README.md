# @thesvg/ui-react

Components for the UI icons from [thesvg.org/ui](https://thesvg.org/ui). One file per icon and one export per look: `BellIcon` is outline, the others add the look (`BellGlassIcon`, `BellDuotoneIcon`, `BellOffsetIcon`, `BellFillIcon`, `BellGlassOutlineIcon`, `BellDepthIcon`). Icons use `currentColor` and take a `size` prop and a `shadow` prop (`true`, or an opacity from 0 to 1) that lifts the icon with a soft shadow on every look; everything else is passed to the svg element.

```sh
npm install @thesvg/ui-react
```
