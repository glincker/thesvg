# @thesvg/ui-svelte

Components for the UI icons from [thesvg.org/ui](https://thesvg.org/ui). One file per icon and one export per look: `BellIcon` is outline, the others add the look (`BellGlassIcon`, `BellDuotoneIcon`, `BellOffsetIcon`, `BellFillIcon`, `BellPixelIcon`, `BellDepthIcon`). Icons use `currentColor` and take a `size` prop; everything else is passed to the svg element.

```sh
npm install @thesvg/ui-svelte
```
